    Sobre

    Design sem separar forma de função.

    “Prefiro uma interface que pareça inevitável: cada elemento está ali porque tem uma razão.”

    Sou Paulo Felipe. Minha formação em design gráfico se encontra com programação e análise de dados para construir produtos digitais com personalidade visual e lógica de uso.

    O trabalho passa por hierarquia, fluxo, consistência, legibilidade e detalhes de interação. O objetivo não é decorar uma página: é organizar informação e tornar a experiência mais precisa.
